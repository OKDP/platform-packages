# Changelog

## 0.3.0 (2026-09-11)


### ⚠ BREAKING CHANGES

* **trino:** the storage and metastore parameters and the hiveCatalog name are gone. A Release declares its catalogs in the two lists instead.
* **okdp-examples:** consume connections and parameters instead of the context blob
* parameterize rbac in spark-operator and spark-rbac
* port polaris and hive-metastore to typed Connections
* **spark-history-server:** port to typed Connections, OIDC filter and web proxy fixed
* **superset:** port to typed Connections, access is OIDC only
* **trino:** port to typed Connections, a Hive catalog plus Iceberg REST catalogs
* **jupyterhub:** port to typed Connections and the platform Context
* **airflow:** port to typed Connections and the platform Context
* **control-plane:** replace okdp-server and okdp-ui with the control plane packages
* packages now publish to quay.io/okdp/platform-packages (no -v0.3 suffix)
